## Constants.js

Central file for all shared constants used across the project. Nothing should be hardcoded elsewhere if it's a magic number or a fixed string, it lives here.

### KEYS

Maps action names to their corresponding keyboard key or mouse button. The Parser uses these to figure out what action a keypress corresponds to.

### PlayerStates / NonPlayerStates / EnviromentStates

String constants for the possible states of the player, NPCs, and environment objects (like chests). Used when calling `SetState()`.

### PlayerSize / ScreenSize

Pixel dimensions of the player sprite and the game screen. `ScreenSize._GROUND` is a derived value the Y coordinate of the ground (bottom of screen minus player height).

### PlayerPhysics

Tuning values for how the player moves: walking speed, sprint multiplier, gravity strength, and jump force. Tweak these to change how the game feels.

### PlayerAnimations

Maps each state name (e.g. `"walk"`, `"jump"`) to an array of sprite frame coordinates, generated by `getSpriteLoc()`. Each frame is an `{x, y}` offset into the spritesheet.

### getSpriteLoc(amountOfFrames, spritesheet_row, startFrame)

Helper function that calculates pixel coordinates for each frame on the spritesheet. `startFrame` lets you skip the first few frames of a row (used for the jump/fall frames which share a row).

## Entity.js

Base class for everything in the game that exists in the world.. players, enemies, chests, etc. Holds shared logic so babies don't repeat themselves.

### Fields

| Field                 | Description                                       |
| --------------------- | ------------------------------------------------- |
| `entityState`       | Current state string (e.g.`"idle"`, `"walk"`) |
| `entityPositionX/Y` | World coordinates                                 |
| `entityVelocityX/Y` | Current speed per axis                            |
| `entityHealth`      | HP,`null` for things that can't die             |
| `ctx`               | The shared canvas layer context to draw onto      |

### Constructor

Takes `{x, y, health}` as a destructured object with defaults, so you can pass only what you need.

### Key Methods

- **`Move(delta)`** — Advances position by velocity × delta. Called every frame.
- **`MoveTo(x, y)`** — Teleports to exact coordinates.
- **`SetVelocity({x, y})`** — Updates velocity. Accepts partial input (only pass the axis you want to change).
- **`SetState(state)`** — Updates `entityState`.
- **`SetHP(value)` / `UpdateHP(value)`** — Sets or modifies HP.
- **`CreateThing({ctx, ...})`** — No longer creates its own canvas. Takes the shared entity layer context and stores it, along with element dimensions.
- **`LogStat()`** — Dumps current state to the console for debugging.

## Player.js

Extends `Entity`. The main character. Handles input, movement, animation, and rendering.

### Additional Fields

| Field               | Description                                                    |
| ------------------- | -------------------------------------------------------------- |
| `playerInventory` | The player's `Inventory` (5 slots)                           |
| `playerEquipment` | Currently held/equipped item                                   |
| `playerStamina`   | Stamina (not yet implemented)                                  |
| `#JumpOnce`       | Private flag to track if a jump was initiated, useless tho     |
| `animationLocked` | Prevents state changes mid-animation (for one-shot animations) |
| `gameFrame`       | Current frame index of the active animation                    |
| `direction`       | `1` = facing right, `-1` = facing left                     |

### Update(delta, keysDown)

Called every frame by the game loop. Runs input handling, then movement, then animation in that order.

### HandleX / HandleY

Separate methods for horizontal and vertical movement logic. HandleX reads left/right/sprint keys and sets X velocity. HandleY handles jumping and gravity. checks if the player is grounded before allowing another jump.

### HandleAnimation

Decides which state to set based on current velocity and whether the player is airborne. Does not override `animationLocked` states.

### SetState(state, once)

Overrides Entity's version. Resets `gameFrame` and `animationTimer` on state change. The `once` parameter locks the animation so it plays through fully before the state can change again.

### PlayPlayerAnimation(state, delta, direction)

Handles the actual canvas rendering. Advances the frame timer, looks up the correct sprite coords from `PlayerAnimations`, and draws the frame onto the shared entity canvas at the player's world coordinates. Handles horizontal flipping for left-facing movement using `ctx.scale(-1, 1)`.

### CreateElement

Gone. Player no longer owns a canvas. It gets the shared entity layer context passed in through the constructor and draws directly onto that.

## Parser.js

Listens to keyboard and mouse events and keeps track of which action keys are currently held down.

### How it works

On construction, it attaches `keydown`, `keyup`, `mousedown`, and `mouseup` listeners to the window. When an event fires, `parseKey()` translates the raw event code into a game action constant from `KEYS` (e.g. `"KeyA"` → `KEYS._LWD`). That constant is then stored in or removed from the `keysDown` object.

### getKeysArray()

Returns the current `keysDown` object. Keys present in the object are currently held down.

## Game.js

The top-level class that owns everything and drives the game.

### Constructor

Creates instances of `Parser`, `World`, and `Window`. Player is no longer created here since it needs the canvas layers to exist first.

### Play()

Entry point. Calls `world.CreateLayers()` first, then creates the Player with the entity layer context, generates the world, loads the start window, and kicks off the animation loop with `requestAnimationFrame`.

### loop(timestamp)

The main game loop, called every frame. Calculates `delta` (time since last frame in ms), clears the entity layer, then calls `player.Update()`. The world update is commented out because it doesn't exist yet, duhh

### Pause() / Resume()

`Pause` cancels the loop. `Resume` resets `lastTime` to zero and restarts it, which prevents a massive delta spike from the time the game was paused.

### Debug()

Exposes key instances (`player`, `world`, `game`) and constants to the browser's global `window` object so they can be inspected in the console during development.

## World.js

Responsible for generating and managing the game world. `GenerateWorld()` only logs a confirmation message rn.

### CreateLayers()

Creates 4 stacked full-screen canvases and stores their 2D contexts. Each layer has a z-index so they stack correctly.

| Layer | ID           | When to redraw              |
| ----- | ------------ | --------------------------- |
| 0     | `background` | Once, never touch again     |
| 1     | `world`      | On camera scroll            |
| 2     | `entities`   | Every frame                 |
| 3     | `hud`        | On state change             |

### ClearEntityLayer()

Clears the entity canvas. Called at the top of every frame in the game loop before anything draws.
